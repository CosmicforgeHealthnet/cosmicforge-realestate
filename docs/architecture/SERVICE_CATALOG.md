# Service Catalog

| Service | Primary ownership |
|---|---|
| api-gateway | External routing, edge policies, aggregation where justified |
| identity-service | Accounts, authentication, roles, sessions, account security |
| property-service | Permanent property identity, structures, ownership associations |
| verification-service | User/business/property/professional verification and authority evidence |
| marketplace-service | Listings, publication, marketplace inventory, discovery metadata |
| transaction-service | Applications, viewings, offers, rental/sale transaction lifecycle |
| agreement-service | Lease/sale/management agreements and signing lifecycle |
| payment-service | Collections, deposits, refunds, settlements, ledger, Paystack, reconciliation |
| property-operations-service | Tenancy, renewals, move-in/out, inspections, utilities, manager assignments |
| maintenance-service | Maintenance cases, quotes, work orders, completion and warranty evidence |
| professional-services-service | Lawyer/surveyor/valuer/inspector engagement workflows |
| hospitality-service | Short-let/hotel inventory, booking, calendar, check-in/out and operations |
| notification-service | System-generated push, SMS and email notifications |
| trust-safety-service | Fraud, disputes, reports, moderation, evidence cases and appeals |
| admin-service | Internal administration, approvals, operational controls and configuration |
| analytics-service | Product, portfolio, trust and market analytics |
