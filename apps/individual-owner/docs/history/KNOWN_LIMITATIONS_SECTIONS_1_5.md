# Known limitations · Sections 1–5

- Full 30-module workflows are unfinished. The dashboard is a foundation, and other areas are navigation placeholders with explicit NOT_STARTED copy. Property detail is a read-only fictional overview. There are no listing/property creation, legal, account, financial or provider workflows yet.
- All owner records are fictional, in memory and reset on reload/restart. There is no durable draft storage, authentication, private customer data, offline command queue, production authorization or live integration. Displaying an example balance does not move or protect money.
- Owner services, payment/verification/media/notification services, CF Meet and hardware providers remain disconnected. All related controls are unavailable. The local task checkbox is solely a demo checklist and is not a maintenance approval or legal/financial decision.
- Web theme is stored locally when browser storage permits; Flutter uses the system theme with a session override. Synced theme/account preferences are later work.
- Original references are preserved byte-for-byte, including unverified financial/legal/security content. Archived HTML may load external design assets if opened. Neither application imports it or copies embedded access examples. Local PNGs and the gallery work offline.
- Font/logo/property media are provisional for public launch. Inter and fallback Roboto include their licenses; property illustrations are local synthetic SVGs. Generated Flutter launcher icons are development placeholders, not approved brand artwork.
- Full accessibility audit, localization, jurisdiction/date preferences, large-text native QA, tablet/device matrix, full visual parity and all module exception states belong to later functional acceptance. Existing focus/labels/landmarks, keyboard controls, reduced-motion styling and state widgets are a foundation.
- No physical Android/iOS device was connected, and `flutter emulators` reports no configured emulators. Windows cannot build iOS without macOS/Xcode. The Android debug APK built successfully; it has not been installed or run on a device. `flutter doctor` also reports some Android SDK licenses unaccepted, although these did not block this debug build. No licenses were accepted by this task.
- Clean dependency resolution and lockfiles are provided. `npm audit --omit=dev` reports zero vulnerabilities. Full `npm audit` reports five high development-tool findings through Next ESLint → fast-glob → micromatch → braces (GHSA-vfj7-8cjw-p6xm). The registry's latest braces is 3.0.3, within the advisory range; no compatible upstream fix was available. The suggested force fix downgrades Next ESLint to 14 and was not applied. ESLint 9.39.5 also emits a deprecation notice. Revisit this toolchain before release.
- Native signing/store release configuration remains development scaffolding. No release certification, deployment, merge or full mock approval has occurred.

Untracked user documents, scripts and Word lock files that were present or appeared during work are left untouched and excluded from implementation commits.
