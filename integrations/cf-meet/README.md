# CF Meet integration

CF Meet is the communications authority for:
- human-to-human messaging;
- voice calling;
- video calling;
- virtual property viewings;
- communication contexts;
- privacy/contact relay.

Real Estate services store only their business context and CF Meet references. They do not implement RTC/chat infrastructure.

Phase 2/V2 use remains configuration-gated until the public API cutover is complete.
